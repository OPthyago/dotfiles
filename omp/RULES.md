# Atribuição de IA — regra absoluta

NUNCA JAMAIS adicione co-author, "Generated with AI/Claude/Codex/etc.", assinatura de IA, ou qualquer menção de que o trabalho foi feito com auxílio de IA em:
- Mensagens de commit (nenhum trailer `Co-authored-by: ...`, nenhum footer "Generated with ...")
- Pull requests (título, descrição, comentários)
- Issues, changelogs, ou qualquer outro artefato do repositório

Isso vale para TODAS as sessões, em TODOS os projetos, com QUALQUER modelo/provider usado dentro do OMP — não é específico de Claude. Commits e PRs devem parecer 100% autorados pelo usuário.
